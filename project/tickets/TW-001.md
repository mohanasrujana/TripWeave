# TW-001 — Confirm product and engineering constraints

- Status: Complete
- Completed: September 1, 2026
- Commit: `f1a155e` (`close TW-001 toolchain setup`)

## Goal

Set the project constraints before writing application code so that the API,
web client, local infrastructure, and future CI use the same tools.

## What I did

- Reviewed the product vision and accepted the Phase 1 scope and non-goals.
- Confirmed that I can spend 15 focused hours per week on the project.
- Chose Java 21 and Maven for the backend.
- Chose Node.js and npm for the frontend.
- Chose Docker Desktop with Docker Compose for local infrastructure.
- Decided to implement authentication in-house during Phase 1, behind an
  identity boundary so it can be replaced later without changing domain code.
- Installed and selected Java 21 instead of the Java 23 runtime that was active
  initially.
- Installed Docker Desktop and verified that the Docker engine and Compose
  plugin work.
- Recorded the decisions and verified versions in ADR 001.

```bash

```

The final Docker smoke test printed `Hello from Docker!`, confirming that the
CLI could communicate with the engine and run a container.

## Problems I ran into

- Java 23 was initially active even though the project required Java 21. I
  installed Temurin 21 and verified that a new shell selected it.
- Docker and Compose were initially unavailable. Installing and starting Docker
  Desktop resolved the blocker.
