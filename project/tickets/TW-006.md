- Status: Review — local verification complete; hosted CI pending

## Goal

Make API and web checks repeatable on pushes to `master` and from a clean checkout.

## Acceptance criteria

- [ ] CI runs API and web checks on pushes to `master` (workflow implemented;
  first hosted push-to-master run pending).
- [x] The local runbook contains exact setup and verification commands.
- [x] A clean checkout builds using only documented prerequisites.

## Implementation

- Added separate API and web GitHub Actions jobs on pushes to
  master and manual dispatch, with read-only repository permissions and timeouts.
- API CI starts the existing digest-pinned PostGIS Compose service, waits for
  health, runs Maven verification, and removes its disposable database.
- Web CI selects Node 26.8.1 and npm 11.19.0, installs locked dependencies, and
  runs the existing full check command. `.node-version` records the Node pin.
- Replaced the draft runbook with prerequisites, setup, checks, application
  startup, troubleshooting, and isolated clean-checkout verification commands.
- Updated the README entry point and recorded toolchain drift in ADR 001.
