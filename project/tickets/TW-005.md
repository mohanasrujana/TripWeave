## Goal

Prove one complete request path from the React client through Spring Boot to
PostgreSQL by creating and retrieving a minimal trip.

## What I built

- Added Flyway migration `V2__create_trips.sql` with UUID identifiers, a name,
  date range, IANA time zone, creator ID, and creation timestamp.
- Added database constraints for nonblank names and ordered date ranges.
- Added JDBC persistence for creating and retrieving trips.
- Added service rules for IANA time-zone validation and missing trips.
- Added `POST /api/trips` and `GET /api/trips/{id}`.
- Added consistent `400` validation responses and `404` not-found responses.
- Added a typed React API client and accessible trip form.
- Added submitting, success, and error states and rendered the saved trip.
- Kept money, voting, invitations, and authentication out of scope.
